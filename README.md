# Pilotage ACI – CPTS Artois Lys (formulaire)

Page web statique publiée avec GitHub Pages. Elle ne contient **aucune donnée** : elle lit et écrit les
données du suivi dans le dépôt privé `pilotage-cpts-data` (voir le README de ce dépôt).

1. Modifier `config.js` : `dataRepo: 'CPTSArtoisLys/pilotage-cpts-data'`.
2. Settings > Pages > Source : branche `main`, dossier `/ (root)`.
3. Ouvrir `https://CPTSArtoisLys.github.io/pilotage-cpts/` et coller le jeton d'accès (voir le dépôt de données).
